# Changelog

## 0.1.0 - 2026-10-12

First public release.

- Browse your reMarkable Cloud library: folders, covers, list and grid views, search, sort, favourites, light and dark themes.
- Read notebooks and annotated PDFs with your handwriting, typed text and highlights, opening on the page the tablet last showed.
- Import PDFs, EPUBs and images; create folders; move documents with a dialog or by drag and drop.
- Export documents as the original file, a rendered PDF or SVG pages, from the viewer or straight from the library.
- Storage settings for the local cache (100 MB, 500 MB, or the whole library for offline use).
- `turborm-cli` command-line client and a Claude Code skill for handwritten reviews on the tablet.
- Nothing in your cloud library is ever deleted: writes only add or move entries, are verified after upload, and are refused if the tablet changed the library at the same time.
